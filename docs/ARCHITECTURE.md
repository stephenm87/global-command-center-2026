# Architecture

The application is a Single Page Application (SPA) built with React and bundled via Vite. It communicates with a serverless backend hosted on Netlify Functions and uses Supabase for authentication and user preferences.

## Frontend
- **Framework**: React 18 bundled with Vite 5, matching the repository toolchain contract
- **Application views & decomposed workspace**: `src/App.jsx` coordinates the URL-addressable Live Globe and Guided Briefings views (redirecting legacy `?view=nexus` links directly to Guided Briefings) while delegating pure URL/clustering/accent helpers to `src/navigationState.mjs`, canonical actor labels and legacy `?actor=` normalization to `src/briefingActors.js`, cloud/local preference hydration to `src/hooks/useSupabasePreferences.js`, lazy WebGL Globe lifecycle and layer synchronization to `src/hooks/useGlobeLayerSync.js`, and focused UI panels to `src/components/IntelSidebar.jsx`, `src/components/OperationalDashboard.jsx`, `src/components/DetailModal.jsx`, `src/components/MineralsModal.jsx`, and `src/components/AppFooter.jsx`. Briefing tour/step selections are encoded in query parameters for refresh-safe links.
- **Visualization modules**: `Globe.gl` and `Three.js` render the live 3D globe (1-tap opt-in on `<768px` mobile viewports, paused whenever hidden). Guided Briefings pairs step narration and perspective readings with `src/components/CaseLocatorMap.jsx` and `src/components/BriefingDepth.jsx` — and for the two 3D actor-map pilot cases (`myanmar-fragmented-sovereignty` and `somaliland-recognition-red-sea-order`), replaces the static locator map with `src/components/CaseActorMap.jsx` (`CaseActorMapFlat.jsx` default/reduced-motion/mobile-initial SVG fallback on 1:110m outlines + lazy-loaded `CaseActorMap3D.jsx` chunk using `globe.gl`, pre-graded static NASA Blue Marble GIBS textures in `public/assets/actor-map/`, 1:50m Natural Earth outlines, pure camera/framing math in `src/components/actorMapCamera.mjs`, and collision-free screen-space label layout in `src/components/actorMapLayout.mjs`); the standalone Nexus workspace and data modules (`NexusWorkspace`, `NexusFocusView`, `nexusFocusData`, `nexusEdgeData`) have been removed.
- **Progressive loading**: The globe, Guided Briefings, and the pilot `CaseActorMap3D` view are split into separate lazy-loaded chunks so `?view=briefings` loads zero WebGL/Three.js code on initial entry, and mobile/low-power viewports stay in the flat SVG actor map until a student taps `Open 3D terrain view` (while desktop viewports load 3D imagery only once scrolled into view).
- **Case-study projection**: `src/caseStudies2026.js` is the canonical source-aware editorial dataset, and `src/nexusTours.js` projects it into guided learning paths backed by actor labels in `src/briefingActors.js`.
- **Intelligence feed composition**: `src/intelFeed.mjs` merges an anonymous cached provider snapshot, the public linked-reference library, verified editorial cases, and legacy forecasts. Cached current records take precedence over exact duplicates, while distinct insights that share a source remain visible. Public references are always loaded independently and are never relabelled as current.
- **Entry Points**: `src/main.jsx` and `src/App.jsx`.

## Backend (Netlify Functions)
Located in `netlify/functions`:
- `ai-summary.js`: Uses Gemini API (`gemini-3.5-flash-lite` default) for authenticated intelligence summarization.
- `deep-scan.js`: Uses Firecrawl for authenticated article extraction with SSRF/URL normalization guards.
- `public-intel.mjs`: Reads the anonymous fixed-query snapshot (including canonical critical-minerals reference metadata) from Netlify Blobs and uses CDN cache headers. It creates the first snapshot on demand if the scheduled job has not run.
- `refresh-public-intel.mjs`: Rebuilds the public snapshot every 6 hours from fixed editorial queries.
- `fetch-news.js`: Runs authenticated visitor-supplied news searches via Serper.
- `source-health.mjs` and `refresh-source-health.mjs`: Publish and refresh the daily editorial link-health snapshot generated from all case-study sources and declared alternates.
- `gemini-retry.js`: Bounded wall-clock retry helper for Gemini API requests.
- `security.js`: Validates Supabase bearer tokens, origin allowlists, and classroom-safe per-user/IP rate limits before provider calls.

The frontend reads `public-intel` without authentication. It uses `src/api.js` to attach the current Supabase access token only to custom search, Firecrawl, and AI-summary requests. Static forecast, linked-reference, verified-case, and historical assets also remain public. If cached current items are unavailable, the interface identifies the precise state and exposes a direct public-source recovery action instead of rendering an unexplained zero.

Provider calls have explicit deadlines. Netlify Blobs provides cross-instance persistence for public snapshots (isolated by deploy context via `snapshot-store.mjs`: site-wide `getStore()` for `production` only, deploy-scoped `getDeployStore()` for Deploy Previews, branch deploys, and non-production contexts across both `public-intel` and `source-health`; `SNAPSHOT_SCHEMA_VERSION = 4` auto-rebuilds stale pre-deploy snapshots on read), and Netlify CDN caching shields free feeds (UN News RSS, BBC World News RSS, headline-only allAfrica.com RSS feeds served from `.rdf` endpoints as RSS 2.0 XML with credit links, Devpolicy Blog CC BY-NC-SA 4.0 labeled explicitly as `analysis`, Global Voices CC BY 3.0 with human author attribution and partner news-organization republication filtering, Mongabay CC BY-ND 4.0 with author attribution and verbatim excerpts labeled `Environmental & conservation journalism` with wire-agency filtering, optional ReliefWeb API v2, and best-effort GDELT; Asia Pacific Report is skipped because it cross-posts RNZ, which forbids aggregation, while RNZ Pacific, Al Jazeera, France 24, and The Conversation remain held) and optional Serper queries from visitor traffic. Live items carry explicit organizational funding labels, author bylines where present, `ANALYSIS` badges distinguishing research analysis (including `research` role domains, which default to `contentType: 'analysis'`) from news, the stricter corporate/political and video-short filter (`minRelevance = 26`, dropping pure business/stock-market stories, non-political `Watch:` / `/videos/` shorts, and items whose only signal is `biodiversity`/`conservation`/`endangered` with no political actor or policy angle) on all configured `public-rss` news-outlet feeds while preserving institutional hubs and snippet-less GDELT discovery at `16`, cap any single publisher at `<= 1/3` when 3+ publishers contribute, prioritize explicit place/country names in the title ahead of nationalities/demonyms across all 193 UN member states plus Hong Kong, Macau (Asia-Pacific), and Taiwan (Asia-Pacific) with ordinary-word collision guards, and leave global stories without a named place unpinned (`Latitude: null, Longitude: null`, `locationPrecision: 'global-unmapped'`). Authenticated custom-search, Firecrawl, and AI responses remain private and are not placed in the shared CDN cache. Durable cross-instance rate limiting for those authenticated endpoints remains separate work.

## Data Layer
- **Supabase**: Handles passwordless OTP authentication and stores user cloud preferences.
- **Local state**: `src/localState.mjs` provides exception-safe JSON persistence. Anonymous dashboard preferences remain available across refreshes, while signed-in dashboard preferences can additionally synchronize through Supabase.
- **Editorial cases**: Twenty-nine dated 2026 records include explicit as-of dates, issue dimensions, uncertainty notes, official or primary source metadata, map locations, and optional alternate source URLs. Coordinates are presentation anchors rather than claims about a single event location.
- **Generated source manifest**: `npm run sources:manifest` projects core, supplemental, and alternate case-study URLs into `netlify/functions/source-health-targets.json`. Tests fail when this committed manifest is stale.
