# AI Functions Integration

The application relies on several AI and data scraping services, orchestrated via Netlify Functions:

1. **Gemini API (`ai-summary.mjs`)**: Generates structured IB Global Politics intelligence briefs defaulting to `gemini-3.5-flash-lite` (authenticated via the `x-goog-api-key` header, top-level `systemInstruction`, fixed `MAX_OUTPUT_TOKENS = 1500`, and `thinkingLevel: 'minimal'` on Flash/Flash-Lite models, with explicit `422`/`502` handling for safety-blocked, recitation, truncated `MAX_TOKENS`, or empty candidates). Rejects request payloads over `64 KiB` (`413`) before parsing, clamps `url` (`2,048`), `title` (`300`), and full user prompt (`15,000`), and counts durable Netlify Blobs per-user/IP + daily quotas (`AI_SUMMARY_DAILY_CAP`, default `200`) before calling Gemini. Tracks elapsed handler wall-clock time from entry (`<22s` ceiling via `gemini-retry.js`; note Netlify's default synchronous function timeout is `10s` unless raised up to `26s` in site settings, while `gemini-3.5-flash-lite` typically responds in `1.5–4s`).
2. **Firecrawl (`deep-scan.mjs`)**: Performs authenticated on-demand article extraction (rejecting bodies over `4 KiB` with `413` before parsing, permitting only one URL per request, upgrading `http://` links to `https://` and running URL/IP/rebinding-suffix validation plus a best-effort `1.5s` DNS pre-check before delegating retrieval to Firecrawl), preserving up to `15,000` characters (lead + conclusion tail) so downstream `ai-summary.mjs` (`12,000`-character selector) retains concluding sections on long-form reports. Enforces durable Blobs per-user/IP + daily quota (`DEEP_SCAN_DAILY_CAP`, default `100`) fail-closed before calling Firecrawl.
3. **Public Serper snapshot (`public-intel.mjs`, `refresh-public-intel.mjs`)**: Runs eight fixed regional and transnational global-issues queries on the server, scores relevance, rejects promotional and weak matches, and selects at most 20 results using region, issue, publisher, topic-cluster, and source-role limits. The balanced snapshot is stored in Netlify Blobs and exposed anonymously. The scheduled refresh runs every 6 hours (`0 */6 * * *`) in production (`~960` queries/month). See [Intelligence Feed Coverage Policy](INTELLIGENCE_FEED_COVERAGE.md).
4. **Protected custom search (`fetch-news.mjs`)**: Accepts a verified caller's topic only after Supabase authentication, optional server-side sign-in allow-list validation, bounded body checks (`4 KiB` -> `413`), 200-char query sanitization, fixed `10`-result cap (`num: 10`), and durable Blobs per-user/IP + daily throttling (`FETCH_NEWS_DAILY_CAP`, default `300`). This is deliberately separate from the public snapshot.
5. **Source health (`refresh-source-health.mjs`, `source-health.mjs`)**: Checks the generated editorial-source manifest daily and publishes non-authoritative availability states (`healthy`, `restricted`, `broken`, or `unknown`) from Netlify Blobs. A health response says whether the checker could reach a URL; it does not validate the article's claims.

Firecrawl is not an anonymous proxy. Article extraction and the downstream AI briefing remain protected because they are expensive, accept visitor-selected URLs, and carry greater abuse and SSRF risk.
