# AI Development Workflow

When working on this repository, AI assistants should:
1. Review `docs/KNOWN_ISSUES.md` before modifying existing features.
2. Run the repository test suite with `npm test`; do not substitute arbitrary commands for the documented checks.
3. Build the project (`npm run build`) to verify syntax and compilation before committing.
4. Update `CHANGELOG.md` when completing major feature tasks.
