# Product Context

**Global Command Center 2026** is an interactive educational tool designed for the IB Global Politics curriculum. 

It aims to provide students with a hands-on, highly visual platform to explore complex global relations, analyze political forecasts, and engage with real-time news intelligence. 

Key user personas:
- **Students**: Exploring global connections, generating AI summaries of events, using the Intelligence Map to build evidence workspaces and essays.
- **Teachers**: Guiding students using the standalone Teacher Guide, reviewing student project reports.
